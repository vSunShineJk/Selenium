This project is an automated testing framework built using Selenium WebDriver, designed to streamline web application testing. It provides a robust structure for writing and executing UI automation tests efficiently, ensuring software quality by automating repetitive manual testing tasks. The framework follows best practices such as the Page Object Model (POM) for maintainability and integrates with JUnit/TestNG for structured test execution.

Key Features
Web UI Automation: Automates interaction with web elements using Selenium WebDriver.
Page Object Model (POM): Implements a modular design for reusability and easy maintenance.
Cross-Browser Testing: Supports multiple browsers (Chrome, Firefox, Edge) for compatibility testing.
Data-Driven Testing: Reads test data from Excel, CSV, or JSON to run tests with different inputs.
Explicit & Fluent Waits: Uses advanced wait mechanisms to handle dynamic web elements.
Headless Browser Testing: Enables execution without UI interaction using Chrome Headless mode.
Logging & Reporting: Generates logs with Log4j and test reports using Extent Reports/TestNG Reports.
Parallel Execution: Runs multiple test cases simultaneously with TestNG/JUnit configurations.
CI/CD Integration: Configured for automated execution via Jenkins, GitHub Actions, or other CI/CD tools.

Tech Stack
Automation Framework: Selenium WebDriver
Test Runner: JUnit / TestNG
Design Pattern: Page Object Model (POM)
Data Handling: Apache POI (Excel), JSON, CSV
Build Tool: Maven
Reporting: Extent Reports, TestNG Reports
Version Control: GitHub
CI/CD: Jenkins, GitHub Actions
